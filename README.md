## Cómo trabajar

Realiza las actividades en tu repositorio privado de prácticas.
Este repositorio contiene los materiales del docente, no tus entregas.

Para preparar tu repositorio, sigue la
[práctica 0-B](https://www.apuntesinformaticafp.com/actividades/preparacion/repositorio-practicas.html).
Después, consulta las instrucciones de cada actividad.

## Cómo presentar una práctica

Cada práctica se entrega en el directorio de su UD de tu repositorio privado
(`ud01/practica.md`, `ud02/practica.md`…), junto con los archivos que pida el
enunciado (por ejemplo, los bocetos de la práctica 1).

Sobre el commit que presentas, crea y publica la etiqueta
`practica-dasp-NN-vM` (por ejemplo, `practica-dasp-01-v1`): esa versión es la
que se corrige. Para una segunda o tercera presentación usa `-v2` o `-v3`,
sin borrar ni mover las anteriores. La etiqueta publicada señala la
presentación; no necesitas enviar otro aviso.
